# WebMarket

Кликабельный прототип интернет-магазина (одежда, обувь, электроника, аксессуары, товары для дома). Чистый HTML/CSS/JS без сборки и зависимостей — открывается прямо в браузере.

Бэкенда нет: корзина, избранное, промокод и последний заказ хранятся в `localStorage` браузера. Все 27 товаров, изображения (SVG-заглушки), отзывы и характеристики — статичные демо-данные в `js/products.js`.

## Как открыть

Просто откройте `index.html` двойным кликом — сайт полностью работает по `file://`, без сервера.

Для показа с локального сервера (по желанию, например чтобы проверить в нескольких вкладках с общим состоянием):

```
py -m http.server
```

и откройте `http://localhost:8000`.

## Структура

```
index.html        главная (баннер, категории, хиты продаж)
catalog.html       каталог (?q=, ?category=) — фильтры, сортировка, пагинация
product.html        карточка товара (?id=)
cart.html            корзина
checkout.html         оформление заказа (степпер: доставка → оплата → готово)
favorites.html         избранное
404.html                страница не найдена
css/style.css            дизайн-система и все стили
js/products.js             каталог товаров (window.Catalog)
js/state.js                  состояние приложения (window.Store)
js/app.js                     общий UI: шапка, подвал, поиск, тосты, модалка (window.UI)
js/catalog.js, product.js, cart.js, checkout.js, favorites.js, index.js — логика страниц
```

## Что показать

1. Главная → живой поиск с подсказками → каталог: фильтры по категории/цене/рейтингу, сортировка, «Показать ещё».
2. Карточка товара: варианты (размер/цвет/память), количество, «В корзину» / «Купить сейчас», вкладки с отзывами.
3. Корзина: изменение количества, промокод, удаление товара.
4. Оформление заказа: маски телефона и карты, степпер, экран успеха (переживает обновление страницы).
5. Избранное, пустая корзина, «ничего не найдено», несуществующий товар (`product.html?id=9999`) — всё без ошибок в консоли.
6. Мобильная версия (375px): бургер-меню, выезжающая панель фильтров снизу.

**Промокод:** `SALE10` — скидка 10% на сумму заказа.

## Вне скоупа

Регистрация и авторизация (кнопка «Войти» — демо-заглушка), личный кабинет, кабинет продавца, админка, реальный платёжный шлюз, SEO, тесты, поддержка старых браузеров.
